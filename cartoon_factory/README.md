# Cartoon Factory

Automated 2D cartoon episode pipeline for fixed recurring characters.

Goals:
- 10 persistent characters across the full series
- automatic story, dialogue, voice, music/SFX, scene plan, rendering and QC
- n8n orchestration
- RunPod/ComfyUI only for GPU-heavy generation
- cheap 2D puppet/sprite rendering for recurring animation

See `config/series.yaml` and `orchestrator/main.py`.
