# Multilingual Dubbing

Target production languages are Turkish, German, Arabic, French, Spanish, and English. Kurdish is tracked as an additional language but must not silently fall back to a wrong-language voice.

- Preserve story meaning, character intent, names, canon, and educational purpose.
- Do not translate literally when natural child-friendly phrasing requires adaptation.
- Never fabricate a translation when a language pass has not been completed.
- Persist every localization version and require review before TTS.
- Use locked terminology memory for recurring names, places, catchphrases, and educational concepts.
- Mark each line as translation_required, review_required, approved, source_ready, or rejected.
- Verify that the selected voice provider explicitly supports the target language.
- Keep dubbing timing compatible with scene duration; timing QA happens before final mix.
