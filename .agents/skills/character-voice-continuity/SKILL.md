# Character Voice Continuity

Use the Character Bible and persistent Voice Continuity Store before producing any voice job.

- Every recurring character has an explicit per-language voice binding.
- Never silently fall back to another language or invent a replacement voice.
- Keep age, relationship, pronunciation, pacing, and emotional range consistent.
- Treat reference audio as private production data.
- A provider, voice ID, reference-audio, or speaking-style change requires an explicit owner override.
- Record provider, voice ID, language, version, and reference-audio provenance in the episode audio manifest.
- Use cross-language voice cloning only with a provider explicitly approved for that target language.
