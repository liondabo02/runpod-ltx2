# Character Voice Continuity

Use the Character Bible before producing any voice job.

- Never invent a new voice identity for an existing character.
- Keep age, relationship, pronunciation, pacing, and emotional range consistent.
- Treat reference audio as private production data.
- A voice change requires an explicit owner-approved canon update.
- Record provider, voice ID, language, and version in the episode audio manifest.
