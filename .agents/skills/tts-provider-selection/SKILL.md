# TTS Provider Selection

Use the Technology Radar and Audio Provider Registry.

- Prefer already-deployed, commercially suitable providers when quality is sufficient.
- Do not use a research/non-commercial model as a default for monetized production.
- Require owner approval before enabling a new paid external provider.
- Keep provider adapters swappable; never hard-code the studio to one vendor.
- Validate language support instead of assuming it.
