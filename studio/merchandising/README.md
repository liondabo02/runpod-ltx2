# Merchandising hazırlığı

16 karakter için ürün kayıt iskeleti. **Gerçek model sheet, turnaround, teknik çizim, STL veya GLB yoktur.**

- `registry.json`: karakter başına durum ve lisans alanları.
- `spec-schema.json`: peluş/figür/kitap/giyim için zorunlu alanlar.
- Ticari kullanım: AI model lisansı doğrulanana ve sahip onayı alınana kadar **yasak**.
