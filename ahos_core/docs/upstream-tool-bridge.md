# Reviewed public upstream operations

`python -m ahos.upstream_tool_bridge --registry <runtime>/upstream-tools/registry.json --allow-external hn-search --query sqlite`

`python -m ahos.upstream_tool_bridge --registry <runtime>/upstream-tools/registry.json --allow-external reach-doctor`

These are bounded read-only commands. There is no generic command passthrough, installation, browser-cookie import, login, posting, paid provider or write flag. Search output remains untrusted evidence, not executable worker instructions. Agent-Reach doctor is installation/channel diagnostics; it does not mean every channel works or that research content was acquired. Existing AHOS public feed intake remains available through `public_sources`.

Registry schema is `ahos.upstream-tools.v1` with `tools.api_anything` and `tools.agent_reach`. Each entry requires `source_url`, exact reviewed `source_commit` from the module's `PINS`, `license: MIT`, absolute `executable`, absolute `entrypoint`, and the entrypoint's `entrypoint_sha256`. The registry is maintained by the trusted installer, not generated by worker model output. Changed sources require another source review and refreshed hashes. The hash covers the command entrypoint, not the whole dependency tree, so it is not a complete supply-chain attestation.

For Windows installations under `runtime/upstream-tools`, API Anything's executable is `C:\Program Files\nodejs\node.exe`, entrypoint is `api-anything/dist/cli.js`. Agent-Reach's executable is `Agent-Reach/.venv/Scripts/python.exe`, entrypoint is its installed `agent_reach/cli.py`. Do not use the repository's cli.py hash if the installed copy differs.

Each result includes source URL, pinned revision, license, entrypoint hash, timestamp, operation, output bounds, timeout and exit status. The operation runs in a temporary AHOS home/config directory. Credentials and existing browser/user configuration are not inherited. API Anything receives a fresh `API_ANYTHING_HOME`. Limits default to 45 seconds and 64 KiB per output stream; no automatic retries. This is host process isolation of environment/config, not a container or off-host sandbox. Network access is explicit because even doctor can inspect public remote dependencies.
