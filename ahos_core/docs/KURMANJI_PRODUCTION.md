# Professional Kurmanji production profile

AHOS publishes Kurmanji under normalized BCP 47 tag `ku-latn` and the audience
label **Kurmancî / Kurdî**. The editorial target is a neutral, child-friendly
Southeast-Turkey register intended to remain understandable across
Adiyaman-Kahta, Diyarbakir, Sanliurfa, Batman, and Mardin. It is not presented as
the only Kurdish variety and must not be used as a substitute for Zazaki.

Every spoken line requires named native-speaker review of terminology,
pronunciation, timing, and child-audience register. Orthographic checks use the
Kurmanji Latin alphabet and Unicode NFC. Unexpected letters trigger manual
review rather than destructive automatic rewriting, so Turkish proper names and
legitimate borrowings can be retained deliberately.

The release gate fails closed when any required approval is absent. Automatic
Kurdish TTS is forbidden until a provider and model version have been explicitly
benchmarked and approved. Rights-cleared human studio performance is supported
and still requires final native listening approval.
