# Q99-075 — Ofiste görevin nereye gittiği ve sonucu görünüyor

**Tarih:** 2026-10-25 · **Testler:** 809 passed

## 1. Yeni sekme: **Görevler**

`http://127.0.0.1:8799/` → **Görevler** sekmesi. Fikir gönderdiğinde ofis
otomatik bu sekmeye geçer ve şunu gösterir:

- **Nereye gitti:** departman adı
- **Nereye doğru:** ilerleme yüzdesi (tamamlanan / toplam adım)
- **Sonuç:** adım başına ✅ tamam · ⏳ çalışıyor · ⛔ engel + `N dosya` veya engel nedeni

Canlı örnek:

```
fikir : "Mipiluna icin gece modu dugmesi ekle"
gitti : Oyun Geliştirme Departmanı (3 görev)
takip : %0 · 0/3
  - pending · Oyun Geliştirme Departmanı: Mipiluna icin gece modu ...
```

Fikir işlendikçe aynı satırlarda `✅ done · 1 dosya` görünür; engellenirse
`⛔ blocked · <neden>` yazar.

## 2. Nasıl çalışıyor?

`ahos/tracking.py` fikrin görevlerini kuyruktaki görevlerle eşleştirir
(görev başlığı = görev hedefi) ve şunları döndürür:

```
idea_id · text · department_name · progress · done/total
tasks[]: title · status · mission_id · changed · output · blocker
```

Ofis `/api/office` yanıtına `tracks` alanı eklendi; ekran 3 saniyede bir yenilenir.

## 3. "Beklemesin" ayarı

Fikirler artık **en yeni önce** işleniyor. Sahibin son verdiği iş, eski birikimin
arkasında beklemiyor.

## 4. Daha önce verdiğin fikirler

```
done 3 · running/pending 17+
```

Her biri Görevler sekmesinde kendi satırında; ilerledikçe yüzdeleri artıyor.
