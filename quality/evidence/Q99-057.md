## 2. Hız ölçümü (gerçek)

| Model | Ölçüm |

| 3B | ilk çağrı 7.8 sn (soğuk), sonra kısa yanıtlar hızlı |

(ücretsiz). 7B yalnız elle, uzun işler için.

## 3. Otomatik yedek geçiş (kanıt)

Birincil uç nokta bilerek bozulduğunda:

```
birincil düştü: tüm modeller başarısız: openai/gpt-4o-mini: URLError
yedek (VM 3B) yanıtı: OK
```

Yani ücretli model/API düşse de iş durmuyor; **ücretsiz VM 3B** devreye giriyor.
O da düşerse deterministik işçi devam ediyor — hiçbir durumda görev askıda kalmıyor.

`model.env`:

```
AHOS_FALLBACK_BASE_URL=http://127.0.0.1:11500/v1
AHOS_FALLBACK_MODEL=qwen2.5-coder:3b
AHOS_FALLBACK_TIMEOUT=600
```

## 4. RAM sorunu

- Dizüstünde **model çalışmıyor**: üretim ya API'de ya VM'de.
- Daemon `--executor-mode model` ile RAM kapısını beklemiyor.
- Yani "RAM yüzünden iş aksıyor" durumu ortadan kalktı.
