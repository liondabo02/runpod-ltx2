# Q99-056 — CEO gerçek veriyle konuşuyor + belgelerden beceri öğrenme

**Tarih:** 2026-10-24 · **Testler:** 753 passed, 0 failed

## 1. "CEO beni kandırıyor" eleştirisi haklıydı

Eski CEO, modele "holdingin durumu" diye birkaç sayı verip genel geçer cümle
kuruyordu. Artık:

- CEO'ya **GERÇEKLER bloğu** veriliyor: daemon durumu, teslim oranı, görev sayısı,
  en sık iki sorun, bilgi ağı/beceri sayısı, **kalite kuyruğundaki başlıklar** ve
  **son üç görevin sonucu** (durum + kaç dosya değişti).
- Sistem talimatı: *"Yalnızca GERÇEKLERLE konuş, uydurma; en az bir somut sayı
  kullan, 1-3 uygulanabilir sonraki adım öner."*
- Model sayısız cevap verirse, cevabın sonuna **gerçek durum** otomatik eklenir.

Doğrulanmış cevap (canlı):

```
1. Kabul testi/doğrulama düşüşünü azaltmak için QA süreçlerine headless
   tarayıcı testi ekleyin...
2. Teslimat yok (0 dosya) sorununu çözmek için 27 kayıttaki nedenleri analiz edin...
3. Görev akışını optimize edin; şu anda 1 dosya "blocked" durumda...
```

Yani cevap artık **holdingin gerçek kuyruğundan** ve sayılardan geliyor.

## 2. Belgelerden öğrenme: "ders" değil **beceri kartı**

`ahos/skills.py` eğitim belgelerinden kural çıkarır:

| Alan | İçerik |
|---|---|
| `rule` | tek cümlelik uygulanabilir kural |
| `applies` | kuralın uygulandığı anahtar kelimeler |
| `source` | hangi belgeden geldi |

- Çevrimdışı: başlık + ilk cümlelerden deterministik kart.
- Model açık: "KURAL: … | UYGUN: …" biçiminde 6 kart.
- `knowledge/skills.jsonl`'a **yalnız eklenir**, içerik özetiyle dedupe edilir.

```
$ ahos-skills --runtime-dir runtime --add ...\quality\evidence
öğrenildi: 210 beceri · offline · toplam 210
$ ahos-skills --runtime-dir runtime --add CODEX-HARDENING.md --model
model beceri: 6 kart · model · toplam 216
```

## 3. Nerede kullanılıyor

İşçiye giden prompt artık şu sırayla zenginleşiyor:

1. **Eğitim kütüphanesinden öğrenilmiş kurallar** (göreve en yakın 3 kart)
2. Bilgi ağından belge parçaları (2 parça)
3. Proje dosyaları + görev + JSON şeması

Yani indirdiğin belgeler **kod yazımını doğrudan** etkiliyor.

## 4. Dürüst sınır (önemli)

Bu, modelin **ağırlıklarını eğitmek değil**: kitapları okuyup not çıkarmak gibi.
Gerçek "öğrenme" iddiası için sıradaki adım **sınav döngüsü**: aynı görevleri
kartlı/kartsız çalıştırıp teslim oranını karşılaştırmak ve işe yaramayan kartı
elemek. O ölçüm olmadan "öğrendi" demek doğru olmaz.

İnternet bağımlılığı: bilinen işler için beceri kartları + yerel model (VM)
yeterli olur; **hiç görülmemiş** işler için hâlâ bir modele ihtiyaç var. Belgeler
arttıkça tekrarlanan işlerde dış bağımlılık azalır.
