# Altyapı Departmanı

Bu beceri, **Altyapı Departmanı** departmanının üretim sözleşmesini tanımlar.

## Ne zaman kullanılır

Deliver infrastructure work for the holding within owner policy. Keywords: sunucu deployment devops altyapi monitoring infrastructure.

## Ücretsiz araç seti

- Windows Task Scheduler
- robocopy yedekleme
- uptime izleme

## Beklenen çıktılar

- yedekleme planı
- izleme listesi
- geri dönüş adımları

## Kabul kuralı

- Teslim, departmanın projesindeki `tools/check_offline.py` kapısından geçmeli.
- Belgeler `deliverables/` altına yazılır; en az bir markdown başlığı ve
  120 karakter içerik gerekir.
- Bağımsız QA kanıtı olmadan `completed` yazılmaz.
- Ücretli araç kullanılmaz; maliyet 0 $.
