# Q99-030 — Oracle ücretsiz VM kuruldu, model hızı ölçüldü

**Tarih:** 2026-10-21 · **Durum:** VM çalışıyor · **Karar:** birincil model bulutta (ücretsiz), VM yedek

| Öğe | Değer |
|---|---|
| Örnek | `AHOS-QUALITY-99` · ocid1.instance…zbpr7a |
| IP | **130.61.35.81** |
| Şekil | VM.Standard.A1.Flex · 2 OCPU / 12 GB · AD-2 |
| Bölge | eu-frankfurt-1 |
| İşletim sistemi | Ubuntu 24.04 aarch64 |
| Ollama | `qwen2.5-coder:7b` (4.7 GB), yalnız localhost:11434 |
| SSH | `~/.ssh/ahos-quality-99/oracle_ed25519` (ubuntu) |

| Cloud-init | 3 dk 40 sn'de tamamlandı (`status: done`) |

İlk denemede AD-1 "Out of host capacity" verdi, AD-2 anında oluşturdu; `create_instance.py`
tam da bunun için yazılmıştı.

## Hız ölçümü (CPU çıkarımı)

```
qwen2.5-coder:7b · 10 token · 4.1 tok/s
```

4 tok/s ile 1000 token'lık bir JSON yaması ~4 dakika sürer; görev başına 3 adım
düşünülünce döngü için pratik değil. Bu yüzden:

- **Birincil:** OpenRouter ücretsiz modeli (`cohere/north-mini-code:free`, ~15-20 sn/adım, $0)
- **Yedek:** Oracle VM + 7B (çevrimdışı/bağımsız; SSH tüneli 11500)

SSH tüneli ve VM açık bırakıldı; `Connect-AhosModel.ps1 -VmIp 130.61.35.81` ile
istenildiğinde modele geçilebilir.

## Doğrulama

```
ssh ubuntu@130.61.35.81 "systemctl is-active ollama; ollama list"  → active, qwen2.5-coder:7b
curl http://127.0.0.1:11500/api/tags                               → model listesi
```

7B ile denenen görev (`undefined` etiketini düzelt) **zaman aşımına** düştü
(180 sn sınırı); profil OpenRouter'a geri alındı, daemon `mod=model` çalışıyor.

## Düzeltilen hatalar

- `create_instance.py`: VNIC sorgusu yanlış istemcideydi (`ComputeClient.list_vnics`) →
  `list_vnic_attachments` + `VirtualNetworkClient.get_vnic`.
- `Connect-AhosModel.ps1`: `AHOS-Daemon.ps1` yolu `ops/oracle` altında aranıyordu →
  repo kökünden `control_plane_v2` olarak düzeltildi.

## Kalan

- 7B gerçekten kullanılacaksa 3B/1.5B ile hız/başarı dengesi ölçülmeli.
- VM'in açık kalması ücretsiz kota içinde; yine de kullanılmıyorsa durdurulabilir.
