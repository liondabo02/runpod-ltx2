# Q99-034 — PC kapalıyken bulut işçisi: ilk gerçek bulut teslimatı

**Tarih:** 2026-10-22 · **Durum:** çalışıyor · **Maliyet:** $0

## Ne kuruldu

```
Oracle VM (2 OCPU/12 GB, ücretsiz)          Yerel PC
systemd timer · 60 dk                        Sync-AhosCloud.ps1
  cloud_worker.py                               www → VM
    tasks.json                                  outbox ← VM
    OpenRouter (ücretsiz model)                 python -m ahos.outbox
    ~/ahos/outbox/*.json                          doğrula → uygula / geri al
```

- `ops/cloud/cloud_worker.py` — VM'de yalnız stdlib ile çalışır; görev listesini
  okur, modele JSON yaması üretir, yolu/find'i doğrular, outbox'a yazar.
- `ops/cloud/ahos-cloud-worker.{service,timer}` — saatlik zamanlayıcı (kuruldu,
  ilk çalıştırma yapıldı).
- `ahos_core/ahos/outbox.py` — yerel içe aktarıcı: yol kaçışı reddi, `find`
  eşleşmesi, `tools/check_offline.py` doğrulaması, başarısızlıkta geri alma.
- `ops/cloud/Sync-AhosCloud.ps1` — projeyi gönderir, outbox'ı indirir, `-Apply`
  ile doğrulayıp uygular.
