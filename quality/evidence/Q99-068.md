# Q99-068 — Hedef yürütücüsü: geniş işler sonuna kadar sürüyor

**Tarih:** 2026-10-25 · **Testler:** 782 passed, 0 failed

## 1. Eksik olan şey neydi?

"Stüdyoyu geliştir" gibi geniş bir hedef tek görev değil. Sistem planı ve ilk
çıktıyı üretiyor, sonra **kalan adımları sürdüren bir yürütücü** olmadığı için
duruyordu; kodlama işçisi de "uygun görev yok" diye bekliyordu.

## 2. Ne kuruldu: hedef → adımlar → sırayla yürütme

`ahos/goals.py`:

- Geniş hedef **5 adıma** bölünür: analiz → uygulama-1 → uygulama-2 → kabul
  kapısı → belge.
- Her daemon turu **tek bir bekleyen adımı** görev olarak alır.
- Başarılı adım `done`, başarısız adım **2 denemeden sonra** `blocked` olur ve
  hedef sonraki adımla devam eder (döngü tıkanmaz).
- Hedef ancak tüm adımlar bitince `done`; ilerleme yüzdesi kalıcı.
- Kayıt: `runtime/goals/<id>.json` + `goals-log.jsonl` (yalnız eklenir).

CEO da geniş isteği otomatik hedefe çevirir ("geliştir/iyileştir/büyüt/yenile").

## 3. Canlı kanıt (gerçek hedef)

```
python -m ahos.goals "Mipiluna stud yosunu gelistir"
hedef: G-994d34f00d49 · 5 adım

01:33 created        %0
01:34 analiz    ok   %20
01:35 uygulama-1 ok  %40   → 1 dosya değişti, doğrulama geçti
01:36 uygulama-2     %40   (ilk deneme düştü, tekrar denendi)
01:38 uygulama-2 ok  %60
```

Şu an: **%60**, `active`, kalan 2 adım sırada. Kodlama işçisi artık boşta değil:
her turda hedefin sıradaki adımını alıyor.

## 4. Panelde nereden görülür?

Ofis (`http://127.0.0.1:8799/`) üstünde iki şerit:

- **hedefler:** `Mipiluna stüdyosunu geliştir %60 (active)`
- **son görevler:** saat · durum · kaç dosya · görev adı

Komutla:

```powershell
python -m ahos.goals --runtime-dir runtime          # hedefler ve adımlar
python -m ahos.failure_analytics --runtime-dir runtime
```

## 5. Davranış kuralları (profesyonel taraf)

| Durum | Davranış |
|---|---|
| Adım başarılı | `done`, ilerleme artar, sonraki adım |
| Adım 1 kez düştü | `pending`, tekrar denenir |
| Adım 2 kez düştü | `blocked`, hedef sonraki adıma geçer |
| Tüm adımlar bitti | hedef `done` |
| Kullanıcı aynı hedefi tekrar verirse | aynı hedef (idempotent) |
