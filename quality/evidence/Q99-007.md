# Q99-007 — Codex ↔ DeepSeek ortak görev sözleşmesi

**Tarih:** 2026-10-18 · **Branch:** `quality-99/ahos`

## Sorun

İki ajan aynı holding üzerinde çalışıyor ama yazılı bir görev devri yok: kim hangi işi
yapıyor, kime ait, süresi doldu mu, tamamlandı mı — hepsi sohbet hafızasında.
Bu yüzden aynı dosyaya eşzamanlı yazma ve tekrar eden iş riski var (ölçümde ❌).

## Çözüm

`ahos_core/ahos/taskboard.py` — tek JSON dosyası + OS byte kilidi:

- `enqueue(title)` — kalıcı görev kimliği,
- `claim(owner, lease_seconds)` — aynı anda **tek** sahip; süresi dolmuş kilit yeniden alınabilir,
- `heartbeat(task_id, owner)` — sahiplik sürdürme,
- `complete(task_id, owner, evidence=[...])` — **kanıtsız kapanmaz**,
- `fail(...)`, `release(...)`, `tasks(state=...)`.

CLI: `python -m ahos.taskboard add|list|claim|complete|fail` (`ahos-taskboard` giriş noktası).

## Kanıt

```
python -m pytest -q tests/test_taskboard.py
11 passed
```

Kapsanan davranışlar: tam iş döngüsü, kanıtsız tamamlama reddi, yanlış sahibin
kapatamaması, lease süresi dolunca devralma (attempt sayacı artar), canlı lease
varken ikinci sahip alamaz, release, fail → blocked, **4 iş parçacığı aynı anda
claim ederken tam olarak 1 kazanan**, yeniden açılışta kalıcılık, CLI turu.

## Kullanım sözleşmesi (ajanlar için)

1. İşe başlamadan `claim` — sahip adı `codex` / `deepseek` / `quality-99`.
2. Uzun işte `heartbeat` (lease yenile).
3. Bitince `complete` + `--evidence "komut → sonuç"` + `--file` + `--test`.
4. Yapamıyorsan `fail "<neden>"` — görev `blocked` kalır, başkası devralmaz.
5. Aynı görev kimliği ikinci kez çalıştırılmaz (terminal durum).

## Kalan risk

- Diğer ajanın bu panoyu kullanması sözleşmeye bağlı; zorunlu kılmak için
  `OwnerConsole`/daemon tarafında `claim` entegrasyonu gerekir (sonraki iş).
- Pano tek dosya; çok yüksek eşzamanlılıkta (100+ yazıcı) kilitlenme süresi
  artabilir — şu an 10 sn timeout ile sınırlı.
