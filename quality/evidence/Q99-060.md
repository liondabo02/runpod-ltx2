# Q99-060 — Duruşun nedeni bulundu: model ayarı ezilmişti

**Tarih:** 2026-10-24 · **Testler:** 761 passed, 0 failed

## 1. "Neden durdu?" — gerçek sebep

`runtime/model.env` bizim ücretli ayarımızın **üzerine yerel/ücretsiz moda** yazılmıştı:

```
AHOS_ALLOW_PAID_LLM=0
AHOS_LLM_BASE_URL=http://127.0.0.1:11500/v1   # tünel kapalıydı
AHOS_LLM_MAX_USD=0
AHOS_DAILY_USD=0
```

Sonuç zinciri:

1. Günlük bütçe **0** → her model çağrısı "günlük model bütçesi doldu: $0.0289 >= $0.00" ile düştü.
2. Üretim 0 dosya değiştirdi → teslimat kanıtı yok.
3. Üst üste 3 kanıtsız görev → daemon **kendini duraklattı** (`paused_no_evidence`).
4. Kuyrukta tek bir kalite görevi tekrar tekrar denendiği için döngü tıkandı.

| Düzeltme | Etki |
