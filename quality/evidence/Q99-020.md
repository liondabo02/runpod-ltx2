# Q99-020 — `source_context` güvenlik sınırları test altına alındı

**Tarih:** 2026-10-18 · **Branch:** `quality-99/ahos`

## Neden

`source_context.select_context()` yerel model için "hedef → kaynak dosya" seçimi
yapıyor ve bir dizi güvenlik sınırı uyguluyor (bağlantı reddi, test/sır dosyası
atlama, boyut/girdi tavanları, UTF-8 zorunluluğu). Kapsam **%0**'dı: sınırlar
kanıtsızdı.

## Eklenen testler (`tests/test_source_context.py`, 8 test)

| Test | Doğrulanan |
|---|---|
| Türkçe katlama | `kuyruk`, `GÖREV`, `hafıza` doğru token'lara iniyor |
| Eşleşme + hash | `src/queue.py` seçiliyor, SHA-256 dosyayla birebir, `selection_scope` dürüst |
| Test/sır atlama | `tests/` ve `node_modules/` dışlanıyor, `credentials_*` atlanıyor |
| Eşleşme yok | `ValueError` — uydurma bağlam yok |
| UTF-8 değil | `ValueError` |
| Aşırı büyük dosya | `>256 KB` → `ValueError` |
| Çıktı sınırı | en fazla 3 dosya |
| Geçersiz kök | `ValueError` |

## Sonuç

```
python -m pytest -q tests/test_source_context.py --cov=ahos.source_context
8 passed · kapsam %0 → %98
```
