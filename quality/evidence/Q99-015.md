# Q99-015 — Gerçek etkileşim testi (CDP): kart tıklama → oyun açılıyor

**Tarih:** 2026-10-18 · **Branch:** `quality-99/ahos` · **Araç:** `quality/tools/cdp_interaction_check.py`

## Sorun

Önceki tarayıcı kanıtı yalnız "sayfa yüklendi" diyordu. Kullanıcı bir karta
dokunduğunda ne olduğu ölçülmüyordu.

## Yöntem

Headless Edge + Chrome DevTools Protocol (WebSocket):

1. Sayfa `file://` olarak açılır, `.card` düğümleri beklenir.
2. İlk yüklemede açılan yetişkin ayarları `<dialog>` kapatılır.
3. İlk oyun kartı gerçek DOM `click()` ile tetiklenir.
4. `body[data-scene]`, `.stage` içeriği ve konsol istisnaları okunur.
5. Ekran görüntüsü alınır.

## Sonuç

```json
{
  "cards": 4,
  "dialog": "Mipiluna",
  "dialog_after": null,
  "dialog_action": "closed",
  "clicked_card": "Boyama atölyesi",
  "before": {"scene": "home"},
  "after": {"scene": "paint", "stage": "Boyama Çizim Albüm …"},
  "exceptions": 0,
  "console_errors": 0
}
```

- `scene: home → paint` — tıklama gerçekten oyunu açtı.
- 0 istisna, 0 konsol hatası.
- Ekran görüntüsü: `quality/evidence/interaction.png` (Boyama atölyesi açık,
  yönerge metni, Boyama/Çizim/Albüm sekmeleri görünür).

**INTERACTION_OK**
