# Q99-029 — Ücretsiz uzak model canlıda: ilk gerçek model teslimatı

**Tarih:** 2026-10-21 · **Maliyet:** **$0** · **Durum:** çalışıyor

## Kurulum

`runtime/model.env` (git dışı, runtime klasöründe):

```
AHOS_EXECUTOR=model
AHOS_LLM_BASE_URL=https://openrouter.ai/api/v1
AHOS_LLM_MODEL=cohere/north-mini-code:free
AHOS_LLM_FREE=1
```

- `AHOS_LLM_FREE=1` → sıfır maliyet kabul edilir, ücretli kapı açılmaz.
- Daemon `model.env`'i **kendisi** yükler (`_load_model_env`), böylece bekçi
  yeniden başlatmalarında da ayar korunur.
- Uzak ücretsiz uçta yerel 2 GiB RAM kapısı uygulanmaz
  (`_remote_free_endpoint`); RAM dolu olsa da model seçilir.
- `max_tokens` eklendi (varsayılan ücretsiz uçta 4096): reasoning harcasa bile
  JSON yanıtı için yer kalır.
