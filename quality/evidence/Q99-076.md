# Q99-076 — Daemon neden deterministik moda düşüyordu + fikir kurtarma

**Tarih:** 2026-10-25 · **Testler:** 817 passed

## 1. Belirti

Watchdog daemon'ı yeniden başlattıktan sonra durum:

```
status=quota_wait · mod=deterministic
son görevler: blocked changed=0
```

Yani model hiç çağrılmıyor, deterministik katalog (doygun) 0 dosya değiştiriyor,
görevler engelleniyordu.

## 2. Kök neden

`_select_executor` otomatik modda yalnız **yerel RAM** kapısına bakıyordu:

```
RAM < floor  → deterministic
```

Ücretli model (gpt-4o-mini) RAM istemez; ama kod bunu bilmiyordu. Watchdog her
yeniden başlatmada `--executor-mode auto` verdiği için sistem sessizce yerel moda
düşüyordu.

## 3. Düzeltme

```python
paid = os.environ.get("AHOS_ALLOW_PAID_LLM", "").lower() in {"1","true","yes","on"}
if _model_is_configured() and (paid or remote_free or free >= floor):
    → model
```

Yani **ücretli model RAM kapısından muaf**. Daemon testleri: 35 passed.

## 4. Fikirler neden bekliyordu?

```
done 6 · running 12 · pending 18
```

12 görev `running` kilitliydi (süreç çökünce geri dönmüyordu). Kurtarma eşiği
15 → **5 dakikaya** çekildi ve elle çalıştırıldı:

```
kurtarılan: 9 · bekleyen: 27
```

Artık en yeni fikir önce işleniyor; daemon her 10 tick'te kurtarmayı kendisi
çalıştırıyor.
